# 🗂️ Instructor Database Loader

## 📌 Overview

A small Python script that loads instructor data from a CSV file into a SQLite database table, demonstrating basic file-to-database loading and querying with Python.

## ⚙️ Tech Stack

- Python
- Pandas
- SQLite

## 🚀 How to Run

```bash
pip install pandas
python db_code.py
```

## 📊 Output

- `STAFF.db` — SQLite database containing the `INSTRUCTOR` table loaded from `INSTRUCTOR.csv`
